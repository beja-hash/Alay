Alay

Alay - это веб-сервис, позволяющий размывать выбранные объекты на видео с помощью сегментационной модели SAM (Segment Anything Model).



Принцип работы:

1)Пользователь загружает видеофайл в интерфейс.

2)Из видео автоматически извлекается первый кадр, который используется для выбора области размытия.

3)Пользователь кликает по нужному объекту на кадре — модель SAM определяет контуры объекта.

4)Через короткое время система отображает предварительный результат с размытым объектом и предлагает кнопку «Размыть на всём видео».

5)После обработки пользователь получает итоговое видео, где выбранный объект размывается на всех кадрах.



Tехнологии

Python / FastAPI - серверная часть

Ultralytics SAM / OpenCV / NumPy и тд — сегментация и обработка видео

JS / React — фронтенд для интерактивного выбора объекта

Docker — контейнеризация и запуск
